# Video Report 发布模块合并计划

**目标：** 在一个 `$video-report` 技能中支持制作视频，以及把现成或本次生成的视频准备到五个平台的草稿；默认保留最终发布前的核验边界。

**结构：** 主入口保留制作流程，按任务路由到 `references/publishing.md`。将上游 `oil-oil/video-publisher-skill` 的生产脚本、平台文档和测试固定在 `publisher/`，原 `SKILL.md` 改为 `WORKFLOW.md`，避免发现两个独立技能。保持脚本相对目录和配置／Job 存储格式，保留 MIT 许可证及来源提交。

**范围：** 不安装 Ego Lite，不读取个人账号，不上传真实素材。已有制作脚本、默认模板和音频时间轴不变。发布仅在用户任务要求时启动；缺少发布环境不阻塞视频制作。

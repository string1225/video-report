# 素材与动画实现约定

本次保留8页、精简旁白、1.25倍语速及整句字幕，升级画面与可复用skill。

1. 素材先保存在案例assets中，登记作者、来源、许可、改动和SHA-256。示意素材明确标注，不冒充研究原始记录。
2. `report.media`登记本地图片/视频；`scene.media`引用素材ID。构建时复制到`deck/media/`并写出许可清单，HTML使用相对路径。
3. `motion.enabled`打开逐帧导出。标题、卡片、图表和进度由绝对时间控制；`scene.reveal_cues`可把要点出现绑定到本页整句字幕的起点。
4. `renderFrame(ms)`等待图片加载及视频定位，导出器按`frame/fps`捕获每一帧并直接送入FFmpeg。旁白、字幕和帧数沿用现有采样时间轴，不采用浏览器实时录屏计时。
5. 验证素材缺失/校验失败、许可记录与相对路径、倒放定位的确定性、真实视频帧变化、动画中间态、完整视频帧数及播放器交互。检查开始、中间和结束画面。
6. 更新SOP、案例QA与实测成本，经代码审阅后提交并推送当前分支。

兼容：未开启motion的报告仍可导出静态页。素材是单独授权的第三方内容，不随源码MIT许可重新授权。

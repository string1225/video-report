# 自制申报与持续授权

先继承当前对话和用户已经明确给出的持续授权。用户说“你制作的视频都按自制，不用再确认”等话时，这就是对助手制作成片的长期申报依据；不要在每条视频、补图、增加署名截图、重新剪辑或恢复上传时再次询问。

## 本机保存与使用

把个人偏好保存在 `~/.config/video-publisher/creation-policy.json`；设置了 `XDG_CONFIG_HOME` 时使用 `$XDG_CONFIG_HOME/video-publisher/creation-policy.json`。`VIDEO_PUBLISHER_CONFIG` 只切换任务发布配置，不屏蔽这份用户授权。不要把用户偏好提交到技能仓库，也不要把它写成所有用户的默认政策。

```json
{
  "schemaVersion": 1,
  "assistantCreatedVideos": {
    "declareSelfMade": true,
    "reconfirm": false
  }
}
```

另记用户实际授权原话和授权时间，方便后续任务继承。只在用户明确设定或修改偏好时写入；同一对话的明确授权立即生效，不必等保存后再开始工作。

进入发布交接时读取该文件。确认视频来自本助手的制作流程（例如本次成片、制作记录或其后续剪辑版本）后，将长期依据记入任务记录，并给现有发布 CLI 追加 `--confirm-original-rights`。这是继承已有用户授权，不需要再发一次确认问题。CLI 仍只接收这个单次运行参数，不会自行读取 `creation-policy.json`。

`all_videos_original` 继续表示用户对所有输入视频的原创声明。仅授权“助手制作的视频”时保留普通输入的 `ask_each_run` 配置，不扩大为所有外来文件原创。外部现成视频没有适用的既有依据时，才补问缺失的事实。

## 素材与发布范围

助手制作成片中的地图、配音、动画、截图及必要画面引用按用户给定的自制申报依据处理；补充这些材料不触发二次自制确认。继续核对具体使用范围，保留作者、出处、水印和素材记录，不把自制申报写成第三方素材已取得通用转载许可。

持续自制授权不增加发布平台或发布范围。用户已经要求发布本次视频、更新既有稿件或调整分P时，继承该授权继续执行；只授权制作时仍交付制作结果。账号、精确视频、稿件身份、最终按钮和成功回执照常内部核验，不把这些核验变成重复询问。

# 演示画面与字幕

模板是浅色研究简报：暖白背景、深色正文、绿色强调与少量琥珀色。页面采用清楚的结论标题、证据区和固定来源区。修改任务的品牌或主题可以直接编辑 `assets/theme.css`。

- 每页一个信息任务。用结论句替代“背景介绍”“数据分析”等空标题；正文只放观众需要一起看的内容。
- 封面、四维拆解、证据图、对比、流程、选择建议和收束，使用不同构图。不要所有场景都铺成同一张项目符号页。
- 1920×1080下标题约66px、正文27～38px；封面可更大。字体随画面缩放，实际缩小观看时仍应辨识。
- 页面内容放在设计基准的96px左右边距内，来源区约854px开始，底部留给字幕。图表脚注不要贴近视频字幕。
- 中文首选本机可用的微软雅黑或明确安装的Noto CJK。字体文件需要打包时保留许可证；不要依赖未加载的在线字体。
- 数值、标签、来源和关键文字保留为HTML/SVG。照片或插图仅在解释需要时添加；不能用生成图里的文字承担事实。
- 条形图需说明单位、基线与比较对象；不同研究或不同指标不能只画在一起暗示同量纲排名。
- 动画服务于讲解：要点逐项显现、条形图增长、进度推进；需要看清的原文截图保持稳定。图片、短片及动效时间设置见 [素材与动画](media-and-motion.md)。

逐帧导出先等字体、图片decode和视频seek解码，再检查DOM是否越过内容安全区。动画中间位置也要核对，不能只检查最终静态布局。联系表帮助发现整体问题；字幕必须从最终烧录视频截帧检查。

播放器按旁白时间翻页，支持播放/暂停、上一页/下一页和进度定位。视频导出隐藏播放器控制条，保留独立可编辑HTML预览。
